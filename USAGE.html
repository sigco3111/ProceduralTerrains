1. 시작하기

라이브 데모 바로 사용

가장 빠르게 시작하는 방법입니다. 별도 설치가 필요 없습니다.

브라우저에서 https://sigco3111.github.io/ProceduralTerrains/ URL을 열고 "지형 만들기" 또는 "템플릿 둘러보기" 버튼을 클릭하면 에디터가 시작됩니다.

로컬 개발 환경

전체 기능을 사용하고 빌드/수정하려면 로컬 설치가 필요합니다.

# 1) 클론 + 의존성 설치
git clone https://github.com/sigco3111/ProceduralTerrains.git
cd ProceduralTerrains
npm install

# 2) 개발 서버 시작
npm run dev
# → http://localhost:6061 에서 자동 열림
# → LAN IP 도 출력됨 (같은 네트워크의 모바일에서 접근 가능)

│          │                                                   │

영역위치주요 역할
A 상단 바최상단파일 저장/불러오기, 실행 취소/다시 실행, 월드 모드 전환, 개발자 성능 오버레이

3. 세 가지 월드 모드

상단 바에서 모드를 전환할 수 있습니다. 각 모드는 서로 다른 워크플로에 최적화되어 있습니다.

🟦 타일 모드 (Tile)

│  □  □  □  □                            │

│  □  □  □  □                            │

특징

  • 청크별 LOD가 적용된 고정 지형 보드
  • 페인팅, 다중 타일 어셴블리, 정밀 내보내기에 최적
  • 사각형 또는 원형(디스크) 레이아웃 선택 가능

  • GLB/OBJ/Unity/Unreal로 내보낼 때

5. 핵심 기능 워크플로

5.1 절차적 지형 만들기 (가장 빠른 시작)

1. 홈 화면에서 "템플릿 둘러보기" 클릭
2. 원하는 템플릿 선택 (예: "섬", "산맥", "사막")
3. 자동으로 에디터가 열리고 3D 뷰포트에 미리보기 표시
4. 좌측 툴바에서 "지형" 선택
5. 우측 패널에서 노이즈/모양 파라미터 조정
   → 슬라이더는 GPU 셰이더 유니폼에 실시간 반영
6. 마음에 들면 상단 바 "저장" 클릭
   → IndexedDB에 프로젝트 영구 저장

5.2 노드 그래프로 정밀하게 제어

1. 좌측 툴바에서 "그래프" 또는 모드를 "노드"로 전환
2. 노드 에디터가 열림
3. 노드 추가:
   - 노이즈 노드 (다양한 노이즈 타입)
   - 변환 노드 (add, carve, replace)
   - 마스크 노드 (선택 영역)
   - 출력 노드 (최종 지형)
4. 노드 연결: 출력 → 입력 포트
5. 우측 패널에서 노드별 파라미터 조정
6. 변경 사항은 즉시 3D 뷰포트에 반영

5.3 페인팅 모드 (타일 모드)

1. 모드가 "타일"인지 확인
2. 좌측 툴바에서 "페인팅" 선택
3. 우측 패널에서 브러시 타입 선택:
   - 높이 (Height)        — 지형 융기/함몰
   - 생태계 (Biome)       — 지역 색상 변경
   - 소품 (Props)         — 나무/돌 배치
   - 강 (Rivers)          — 물 흐름
4. 뷰포트 위에서 드래그 → 브러시 적용
5. 우측 상단 슬라이더로 강도/크기 조정

5.4 실제 지형 하이맵 가져오기

1. 모드: 타일
2. 좌측 툴바에서 "가져오기" → "실제 지형"
3. 위치/영역 선택
4. 가져오기 옵션:
   - 미리보기 (Preview)   — 현재 지형 위에 반투명 표시
   - 교체 (Replace)       — 현재 지형 대체
   - 혼합 (Blend)         — 가중치 기반 혼합
5. 적용 → 셰이더에서 즉시 처리

7. 내보내기 워크플로

좌측 �바에서 "내보내기" → "내보내기 패널" 선택.

7.1 빠른 내보내기

형식설명
스크린샷 (PNG)현재 뷰포트 그대로 캡처
하이맵 (RAW)동일 셰이더의 직교 회색조 베이크

7.2 전체 내보내기 (ZIP)

지형 메시는 GLB/GLTF 또는 OBJ로 내보냅니다.

프로젝트.zip
├── terrain.glb           ← 지형 메시
├── textures/
│   ├── albedo.png        ← 베이크된 컬러
│   ├── normal.png        ← 법선 맵
│   └── heightmap.png     ← 높이 맵
├── biome_splat.png       ← 생태계 스플랫 맵
├── collision.glb         ← 충돌 메시
├── water.glb             ← 수면 메시
├── water_masks/
│   ├── depth.png         ← 물 깊이
│   ├── foam.png          ← 거품
│   └── shoreline.png     ← 해안선
└── terrain.json          ← 재가져오기용 프리셋

7.3 프로덕션 프리셋

내보내기 패널에는 엔진을 위한 체크 프리플라이트가 포함되어 있습니다:

엔진특징
Unity Terrain리틀 엔디언 부호 없는 16비트 RAW (.raw / .r16)
Unreal Landscape동일 RAW 형식
Godot Terrain3DGodot 리소스 형식
Blender Scene.blend 호환 FBX
Three.js ViewerglTF + assets 폴더 패키징

terrain.json과 README.txt가 항상 함께 제공됩니다.

8. 성능 최적화

8.1 우측 패널 "성능" 탭

설정조정 방향
픽셀 비율 (Pixel Ratio)약한 GPU → 0.5~0.75로 낮�
LOD 예산 (LOD Budget)삼각형 수 한도를 낮춰 멀리 있는 지형 단순화
노이즈 옥타브 수4~6 옥타브로 감소
물 품질 모드High → Medium → Legacy

8.2 진단 도구

Ctrl+Shift+P  →  개발자 성능 오버레이

오버레이에는 다음이 표시됩니다:

  • GPU 정보 (WebGPU, ANGLE Metal Renderer: Apple M4)
  • 실시간 FPS
  • 드로우 콜 수
  • 삼각형 수
  • 청크 스트리밍 상태

8.3 GPU가 약할 때

  1. 픽셀 비율: 0.5로 시작
  2. 물 모드: Legacy로 전환
  3. 노이즈 옥타브: 4로 감소
  4. LOD 청크 크기: 64 → 96 (메모리 ↓, 디테일 ↓)

9. 문제 해결

9.1 페이지가 하얗게 보임 (흰화면)

원인해결
GitHub Pages 캐시강력 새로고침 (Ctrl+Shift+R / Cmd+Shift+R)
첫 로드 지연부팅 스플래시가 보이면 정상 (3~5초 대기)
GPU 미지원WebGL 2 미지원 브라우저는 작동 불가

9.2 한글이 깨져 보임

브라우저의 인코딩이 UTF-8이 아닌 경우 발생합니다. lang="ko" 메타 태그가 설정되어 있으므로 보통은 정상입니다. 강제로 새로고침하세요.

9.3 성능이 느림

  1. 성능 오버레이 토글 (Ctrl+Shift+P)
  2. FPS가 30 이하라면 위의 성능 최적화 참조
  3. 다른 탭/앱 닫기 (특히 비디오, 3D 게임)
  4. 하드웨어 가속 활성화 (브라우저 설정)

9.4 저장한 프로젝트를 못 찾겠음

  • 프로젝트는 IndexedDB에 저장됩니다
  • 브라우저 데이터 초기화 시 삭제됩니다
  • 정기적으로 내보내기로 백업 권장

9.5 라이브 데모가 안 열림

1. https://sigco3111.github.io/ProceduralTerrains/ 직접 방문
2. 다른 브라우저로 시도 (Chrome / Firefox / Edge 권장)
3. WebGL 2 지원 확인: https://get.webgl.org/webgl2/
4. 1~2분 대기 후 재시도 (Pages 빌드 진행 중일 수 있음)
